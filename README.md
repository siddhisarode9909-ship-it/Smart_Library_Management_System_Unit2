# Smart Library Management System

## Course
Python Programming (IBM) - Unit 2: Data Structures and Collection Management

## Project
Smart Library Management System

## Objective
To use Python Strings, Lists, Tuples, Sets and Dictionaries to store, organize, update, search and report library information.

## Main Features
1. Add Book
2. Search Book by Title
3. Update Book
4. Delete Book
5. Display All Books
6. Find Books by Author
7. Show Unique Categories
8. Count Available Books
9. Sort Books Alphabetically
10. Exit

## Data Structures Used
- String: titles, authors, categories and messages
- List: complete library collection
- Tuple: fixed ISBN information
- Set: unique categories
- Dictionary: complete book record

## How to Run
1. Install Python 3.
2. Open this folder in VS Code.
3. Open `library_system.py`.
4. Open Terminal in VS Code.
5. Run:
   `python library_system.py`

## Supporting Programs
The `programs` folder contains separate demonstrations for strings, lists, tuples and sets.

## Testing
The project includes normal, boundary, invalid-input and duplicate-record test cases in the documentation.
